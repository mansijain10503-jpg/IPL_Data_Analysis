# IPL_Data_Analysis
Exploratory Data Analysis of IPL 2022 using Python, Pandas, Matplotlib, and Seaborn to analyze team performance, toss decisions, player statistics, bowling figures, and match venues.




# 🏏 IPL 2022 Data Analysis Using Python

## 📌 Project Overview

This project explores IPL 2022 match data using Python and
data analysis libraries.

The objective is to analyze team performance, toss decisions,
player statistics, bowling performances, and match venues
through data analysis and visualization.

## 🎯 Objectives

- Analyze the number of matches won by each team.
- Explore toss decision trends.
- Compare toss winners with match winners.
- Analyze match-winning methods: runs and wickets.
- Explore Player of the Match awards.
- Examine top scorer statistics.
- Analyze bowling figures.
- Identify venues hosting the most matches.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset Information

- Tournament: Indian Premier League (IPL) 2022
- Matches: 74
- Columns: 20

The dataset contains information about match venues,
teams, toss decisions, scores, match winners, player
performances, and bowling figures.

## 🔍 Analysis Performed

### 1. Team Performance
Analyzed match wins for each team using value counts
and bar charts.

### 2. Toss Decision Analysis
Explored teams' toss decisions and compared toss winners
with match winners.

### 3. Match Results
Examined whether matches were won by runs or wickets.

### 4. Player Performance
Analyzed Player of the Match awards and top scorer statistics.

### 5. Bowling Performance
Explored the best bowling figures recorded in the dataset.

### 6. Venue Analysis
Identified venues with the highest number of matches.

## 💡 Key Findings

- Gujarat recorded the highest number of match wins in
  this dataset, with 12 wins.
- Toss winner and match winner were the same in approximately
  48.65% of the matches.
- Jos Buttler had the highest aggregated highscore value
  in the top-scorer analysis, with 651.
- Quinton de Kock recorded the highest individual score
  shown in the analysis, with 140.
- Wankhede Stadium, Mumbai, hosted the most matches in
  this dataset, with 21 matches.
